def render_terminal_phase_panel(run_phase: str) -> Panel:
    title = "胜利" if run_phase == "victory" else "游戏结束"
    message = (
        "首领已被击败，本轮冒险已完成。"
        if run_phase == "victory"
        else "玩家已倒下，本轮冒险结束。"
    )
    return Panel(Group(Text(message)), title=title, box=PANEL_BOX, expand=False)

修改 `render_terminal_phase_panel` 函数签名，增加 `run_state: RunState` 和 `registry: ContentProviderPort` 参数（per D-08, D-09, D-10），使其能渲染完整运行统计。

**新签名：**
```python
def render_terminal_phase_panel(
    run_phase: str,
    *,
    run_state: RunState,
    registry: ContentProviderPort,
) -> Panel:
```

**面板内容（per D-08 胜利统计面板，per D-09 失败对称处理）：**
- 标题：胜利时 `"🏆 胜利"` / 失败时 `"💀 游戏结束"`（保持现有逻辑）
- 第一行：状态消息（保持现有逻辑）
- 统计区域（Rich Text.assemble 风格，与现有 render_summary_panel 一致）：
  - `角色`：通过 `registry.characters().get(run_state.character_id).name` 获取
  - `到达章节`：`run_state.current_act_id` 的中文名（通过 `registry.acts().get(...)` 获取，若获取失败则直接显示 act ID）
  - `生命值`：`{run_state.current_hp}/{run_state.max_hp}`
  - `金币`：`run_state.gold`
  - `牌组`：`{len(run_state.deck)} 张`
  - `遗物`：遍历 `run_state.relics`，每个遗物通过 `registry.relics().get(relic_id).name` 获取中文名（获取失败则显示 ID），用顿号分隔
  - `药水`：遍历 `run_state.potions`，获取中文名，用顿号分隔；无药水时显示 `"无"`
  - `种子`：`run_state.seed`

**样式约束（per D-10 共享 Rich 展示层）：**
- 使用现有的 `PANEL_BOX` 和 `Text.assemble(("label ", "summary.label"), value)` 风格
- 胜利面板 title style 用 `"bold green"`，失败面板 title style 用 `"bold red"`
- 不引入新的 Rich 组件，复用现有 Panel + Group + Text 模式

**同步更新调用方：**
在 `render_non_combat_screen` 中，将 `render_terminal_phase_panel(run_phase)` 调用更新为传入 `run_state` 和 `registry` 参数：
```python
if run_phase != "active":
    body.append(render_terminal_phase_panel(
        run_phase, run_state=run_state, registry=registry
    ))
```

同样检查其他调用 `render_terminal_phase_panel` 的地方并更新。

**获取遗物/药水中文名时的容错：** 如果 `registry.relics().get(relic_id)` 或 `registry.potions().get(potion_id)` 抛出 `KeyError`（可能是 placeholder 内容），catch 异常并 fallback 到显示原始 ID。
