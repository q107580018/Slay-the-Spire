2. **`test_three_act_full_run_reaches_victory()`**（per D-11，标记 `@pytest.mark.guardrail`）：
   - `start_session(seed=5)` 开始
   - Force Act 1 Boss 奖励完成 → 选择遗物 → 进入 Boss 宝箱 → 前往下一幕
   - 断言进入 Act 2（`session.act_state.act_id == "act2"`）
   - Force Act 2 Boss 奖励完成 → 选择遗物 → 进入 Boss 宝箱
   - 断言 Boss 宝箱的 `next_act_id == "act3"`（而非终局）
   - 前往下一幕
   - 断言进入 Act 3（`session.act_state.act_id == "act3"`，`session.room_state.room_type == "combat"`）
   - Force Act 3 Boss 奖励完成 → 选择遗物 → 进入 Boss 宝箱
   - 断言 Boss 宝箱显示"完成攀登"（无 next_act_id）
   - 前往下一幕（确认遗物选择后推进终局）
   - 断言 `session.run_phase == "victory"`

3. **`test_act2_boss_transitions_to_act3()`**（per D-12）：
   - 直接构造 Act 2 Boss 奖励完成状态
   - 通过 `route_menu_choice` 选遗物、进入 Boss 宝箱
   - 断言 `session.room_state.payload["next_act_id"] == "act3"`
   - 前往下一幕
   - 断言 `session.act_state.act_id == "act3"`

4. **`test_act3_boss_transitions_to_victory()`**（per D-12）：
   - 构造 Act 3 Boss 奖励完成状态（`current_act_id="act3"`，使用 `generate_act_state("act3", ...)`）
   - 通过 `route_menu_choice` 选遗物、进入 Boss 宝箱
   - 断言 Boss 宝箱消息中包含"完成攀登"
   - 前往下一幕
   - 断言 `session.run_phase == "victory"`
